# meu portifolio

META PROMPT — PORTFÓLIO PESSOAL DE TECNOLOGIA E INOVAÇÃO

Crie um portfólio pessoal premium, extremamente moderno, futurista e tecnológico, com design de nível internacional, capaz de impressionar recrutadores, gestores de tecnologia e empresas de alto padrão.

O objetivo principal do site é apresentar minha trajetória profissional, habilidades técnicas, projetos desenvolvidos, experiências e conquistas de forma visualmente impactante, transmitindo inovação, competência técnica e profissionalismo.
